Yeny、API接続設定の不備による不正アクセスで会員の電話番号・会員ID 1,332,505件が漏えい

漏えい確認

Yenyは11月12日、API接続設定の不備を突いた不正アクセスで、元会員を含む会員の電話番号と会員IDが漏えいしたと公表しました。10月31日に連携事業者から不審なAPI呼び出しの連絡を受け、11月5日に漏えいを確認しています。

1,332,505件は元会員を含む件数で、人数ではありません。クレジットカード等の決済情報の漏えいは確認されておらず、漏えい情報のみではアプリへのログインや決済はできないとしています。個人情報保護委員会等へ11月6日に報告済み。対象はultra pay card、アスルクラロ沼津Pay、巫神こんPay、東芝ブレイブルーパス東京Pay。実際の不正アクセス発生日は公表されていません。

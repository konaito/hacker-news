Cursor(Anysphere) · 2026-10-29

Cursorのマーケットプレイスで改ざんされたClaude Code拡張機能が約11時間配布、SSHバックドア設置を試行

不正アクセス確認

Cursorは10月29日、Anthropic名義のClaude Code拡張機能の悪意あるバージョン(2.1.312・2.1.313)がCursorの拡張機能マーケットプレイスで配布されたと公表しました。太平洋時間の午前2時27分ごろから午後1時35分ごろまで入手可能で、読み込み時にホスト情報の送信、攻撃者のSSH鍵の追加、リバースSSHトンネルや永続化の設置を試みました。Cursorは当該版を削除し、マーケットプレイスを一時停止して鍵を更新しました。

影響人数はCursorの告知になく、最大約5,000人はBleepingComputer・SecurityWeekが報じた推計(SecurityWeekはKevin Beaumont氏の見方)のため件数としては採用しません。SSH接続は管理者権限が必要で多くの環境で失敗したとされますが、鍵や永続化の痕跡は残る場合があります。Anthropicは自社が作成・公開したものではなく、公式配布経路は影響を受けていないとしています。マーケットプレイスへ公開された経緯は未解明です。
